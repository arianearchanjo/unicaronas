O Projeto

O UniCaronas é uma plataforma web desenvolvida como projeto final da disciplina de Prática Profissional em Programação WEB, ao longo de 8 sprints de desenvolvimento. O objetivo é conectar estudantes universitários para compartilhar caronas de forma segura, econômica e sustentável, utilizando o e-mail institucional como forma de autenticação e verificação.

Status do Projeto

O sistema está funcional — é possível se cadastrar, criar e buscar caronas, gerenciar solicitações, conversar via chat e muito mais.

O módulo de processamento de pagamentos não foi configurado no ambiente atual. Em produção real, seria integrado a um provedor de pagamentos (Pix, cartão, etc.).
